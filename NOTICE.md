# Avisos do piloto

Este pacote contém código novo de demonstração do Kelwin Hub. Não redistribui nem incorpora binários ou código-fonte do EspoCRM ou do n8n. O arquivo de workflow n8n é um modelo de configuração, não um fork do n8n.

Dependências Python, SQLite, navegador, Docker, n8n, Tailscale e serviços cloud mantêm seus próprios termos e licenças. Uso interno pessoal do n8n Community está contemplado no FAQ do fornecedor (<https://support.n8n.io/article/can-i-use-your-license-for-my-use-case>); redistribuição do construtor de workflows a terceiros requer análise/licença adequada.

Não há contratação, instância em nuvem, servidor doméstico provisionado, integração OAuth real ou push para GitHub nesta execução.
